# 海外保固與售後：討論資料包

這個資料夾是**討論稿，不是定案，也還沒有任何程式**。目的是讓海外業務同事帶著這些檔案，跟自己的 AI 助理討論「海外保固要怎麼做」，把共識寫回來，再交給工程端實作。

## 要做什麼（一句話）

在全球保固網站的**海外頁**，提供三件事：**保固登錄**、**查詢保固**、**申請維修／聯絡售後**，後兩者最後都會把客人的問題與聯絡方式寄到客服信箱。

```
保固與售後
├─ 保固登錄
├─ 查詢保固
│   └─ 輸入登錄的 Email ─ 一鍵申請維修／聯絡售後 ─ 留下問題和聯絡方式 → 寄到客服信箱
└─ 申請維修／聯絡售後
    └─ 留下問題和聯絡方式 → 寄到客服信箱
```

## 怎麼用（三步）

1. **餵資料**：把整個資料夾的內容交給你的 AI（至少要有 `00`～`04`）。支援上傳檔案的 AI 就直接上傳；不支援的，依序貼上。
2. **開始討論**：用 `05` 裡的提示詞開場，從 `04` 的「卡關」題開始，一題一題談。
3. **寫回結論**：每題談完，把決定填進 `04` 的「決定內容」欄，請 AI 用 `05` 的「決議摘要」格式整理後交給工程端。

## 三條規則

- **不要把真實的客戶個資、密碼、金鑰貼給 AI。** 討論只需要說明欄位與流程，不需要真實資料。
- **AI 不知道的就說不知道。** 這些檔案已標明哪些是已確認的事實、哪些是假設；請 AI 不要自己補編細節。
- **這裡只討論「做什麼、為什麼」。** 程式怎麼寫由工程端決定，討論結果先寫進 `04`，不要直接去改程式。
