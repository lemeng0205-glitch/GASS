# 媒體庫搬遷（ERP → 本網站資料庫）

**決定（2026-11-18）**：媒體庫的資料與檔案改放本網站的 Supabase 專案；維護人員仍在 ERP 後台上傳、覆蓋、下載。ERP **不持有**資料庫金鑰，改為用簽章呼叫本網站的管理 API。

## 結構

```
維護人員 → ERP 後台（權限、2FA 不變）
              ↓ ERP 伺服器端，HMAC 簽章
        本網站 /api/admin/media  ──→  warranty_media_* 資料表 + 私有 bucket warranty-media
                                          ↑
客人 → 本網站 /m/<編號>、/m/<編號>/f/<id>（只讀已上架檔案）
```

## 啟用步驟（階段 1，需要你動手）

1. **建表**：Supabase 專案（保固網站用的那個）→ SQL Editor → 貼上 `docs/sql/002_media.sql` 全部內容 → Run。最後會列出驗證結果，應看到 2 張表（`rls=true`）與 1 個 bucket（`public=false`）。只新增 `warranty_media_*` 與 bucket `warranty-media`，不動其他東西。
2. **管理憑證**：已產生並寫入本機 `樂萌全球保固網站/.env.local` 的 `PORTAL_ADMIN_SECRET`（64 字元，不在 git 裡）。請把**同一個值**貼到 Vercel 保固網站專案（`gass`）的環境變數 `PORTAL_ADMIN_SECRET`（Production），然後重新部署。**不要貼到聊天室或任何文件。**
3. 之後階段 3 才需要把同一個值貼到 ERP 專案。

## 憑證輪換

1. 產生新憑證。2. 網站：把舊值移到 `PORTAL_ADMIN_SECRET_PREV`，新值放 `PORTAL_ADMIN_SECRET`，部署。3. ERP：換成新值，部署。4. 確認正常後，刪除網站的 `PORTAL_ADMIN_SECRET_PREV`。

## 管理 API 規格（給 ERP 端實作用）

`POST /api/admin/media`，body 為 JSON，必帶 `op`；標頭 `x-admin-ts`（Unix 秒，10 碼）與 `x-admin-sig`（`HMAC-SHA256(secret, ts + "." + 原始 body)` 的十六進位小寫）。時間戳誤差超過 120 秒、簽章錯誤、沒設憑證，一律回 404。

| op | 參數 | 回傳 `data` |
|---|---|---|
| `list` | — | 文件陣列（含版本） |
| `upload_url` | `slug`、`lang`、`mime`、`size` | `{ path, token }`（瀏覽器直傳用） |
| `create` | `slug`、`lang`、`title`、`kind`、`sku`、`file`、`actor` | 新文件 |
| `add_version` | `id`、`file`、`actor` | 新版本（覆蓋） |
| `patch` | `id` + `title`／`kind`／`sku`／`is_published`／`slug`／`lang` | 更新後文件 |
| `delete` | `id` | `null` |
| `restore` | `id`、`version_id` | 更新後文件 |
| `download_url` | `id`、`version_id`（選填） | `{ url }`（60 秒、強制下載、原檔名） |

`file` = `{ file_path, file_name, mime_type, size_bytes }`。成功回 `{ success: true, data }`，失敗回 `{ success: false, error }`（中文訊息）。

## 語言與退回規則（公開頁）

`/m/<編號>?lang=ja` → 有日文就直接開；沒有就退回英文；仍沒有才顯示選擇頁。可用逗號指定順序，例如 `?lang=ko,ja`。`zh` 視為 `zh-TW`，不分大小寫。**沒帶 `lang` 且只有一份文件 → 直接開；多份 → 選擇頁。**
新增語言：在 `lib/mediaConfig.ts` 的 `MEDIA_LANGS` 加一行（資料庫不限制語言值）。目前支援 zh-TW、en、ja、ko、de、fr、zh-CN。
